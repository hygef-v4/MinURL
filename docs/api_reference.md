# API Reference - MinURL

This document provides technical details about the API endpoints, URL encoding mechanism, and database setup for the **MinURL** project.

---

## 1. Encoding Mechanism & How It Works

MinURL uses a high-performance URL shortening mechanism based on the database's auto-incrementing primary key (`id`) to guarantee uniqueness and fast lookups.

### Base62 Encoding
To convert an integer ID (e.g., `10348`) into a short string, we use Base62 representation, which utilizes 62 characters:
- `a-z` (26 characters)
- `A-Z` (26 characters)
- `0-9` (10 characters)

**Workflow:**
1. When a user requests to shorten a URL:
   - A new row is inserted into the `urls` table with the `long_url` (and `user_id` if authenticated).
   - Supabase Database automatically generates an auto-incrementing integer `id` (e.g., `id = 12345`).
2. The backend encodes this integer `id` into a Base62 string (e.g., `12345` -> `dnh`).
3. This string is saved as the `short_code` for that record. The backend updates the record in the database with the `short_code`.
4. When a user visits the short URL (e.g., `http://localhost:8000/dnh`), the backend decodes `dnh` back into `12345`, looks up the record by its primary key `id` (extremely fast), retrieves the `long_url`, and performs an HTTP `301` redirect.

## 2. Database Setup (Supabase)

To run the application, you need to create the `urls` and `clicks` tables, along with indexes and database functions in your Supabase PostgreSQL database. Execute the following SQL query in the SQL Editor of your Supabase Dashboard:

```sql
-- Create urls table
create table public.urls (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  long_url text not null,
  short_code text unique,
  clicks_count bigint default 0,
  user_id uuid references auth.users(id) on delete cascade
);

-- Create clicks table for tracking analytics
create table public.clicks (
  id bigint generated by default as identity primary key,
  url_id bigint references public.urls(id) on delete cascade,
  clicked_at timestamp with time zone default timezone('utc'::text, now()) not null,
  referrer text default 'direct',
  country text default 'Unknown',
  city text default 'Unknown',
  browser text default 'Unknown',
  os text default 'Unknown',
  device text default 'Unknown'
);

-- Indexes for performance
create index idx_urls_short_code on public.urls(short_code);
create index idx_urls_user_id on public.urls(user_id);
create index idx_clicks_url_id on public.clicks(url_id);

-- RPC for incrementing clicks_count atomically
create or replace function public.increment_clicks(row_id bigint)
returns void as $$
begin
  update public.urls
  set clicks_count = coalesce(clicks_count, 0) + 1
  where id = row_id;
end;
$$ language plpgsql;
```

## 3. API Endpoints Specification

### 3.1. Health Check
Checks if the backend API server is healthy and running.

- **URL:** `/health`
- **Method:** `GET`
- **Headers:** None
- **Success Response (200 OK):**
  ```json
  {
    "status": "ok",
    "message": "API is healthy"
  }
  ```

---

### 3.2. Shorten URL
Generates a shortened URL from a long URL. Supports custom alias, safe browsing checks, and rate limiting.

- **URL:** `/api/v1/shorten`
- **Method:** `POST`
- **Headers:**
  - `Content-Type: application/json`
  - `Authorization: Bearer <JWT_TOKEN>` *(Optional - Send if user is authenticated to save link in history)*
- **Request Body (JSON):**
  ```json
  {
    "long_url": "https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/301",
    "custom_alias": "my-custom-alias"
  }
  ```
  *(Note: `long_url` must be a valid URL format. `custom_alias` is optional, must be 3-30 characters long, and contain only alphanumeric characters, hyphens `-` and underscores `_`)*
- **Success Response (200 OK):**
  ```json
  {
    "short_code": "my-custom-alias",
    "short_url": "http://localhost:8000/my-custom-alias",
    "long_url": "https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/301",
    "clicks_count": 0,
    "qr_code_url": "http://localhost:8000/api/v1/qrcode/my-custom-alias"
  }
  ```
- **Error Responses:**
  - **400 Bad Request:**
    - The link is unsafe (blocked by local blacklist or Google Safe Browsing API).
    - Custom alias contains invalid characters.
    - Custom alias is a reserved system keyword.
  - **409 Conflict:** The custom alias is already in use.
  - **422 Unprocessable Entity (ValidationError):** Invalid URL format, missing body parameters, or custom alias doesn't meet size constraints (min 3, max 30 characters).
  - **429 Too Many Requests:** Limit of 10 requests per minute exceeded.
  - **500 Internal Server Error:** Failed to save URL or connection issues with Supabase database.

---

### 3.3. Get User History
Retrieves the 20 most recent shortened URLs created by the authenticated user.

- **URL:** `/api/v1/history`
- **Method:** `GET`
- **Headers:**
  - `Content-Type: application/json`
  - `Authorization: Bearer <JWT_TOKEN>` *(Required)*
- **Success Response (200 OK):**
  ```json
  [
    {
      "short_code": "c",
      "short_url": "http://localhost:8000/c",
      "long_url": "https://github.com/hygef-v4/MinURL"
    },
    {
      "short_code": "b",
      "short_url": "http://localhost:8000/b",
      "long_url": "https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/301"
    }
  ]
  ```
- **Error Responses:**
  - **401 Unauthorized:** Invalid, expired, or missing JWT authorization header.
  - **500 Internal Server Error:** Database query error.

---

### 3.4. Redirect Short URL
Decodes the short code, looks up the corresponding long URL, and redirects the client.

- **URL:** `/{short_code}`
- **Method:** `GET`
- **Success Response (301 Moved Permanently):**
  - Redirects the browser directly to the original `long_url`.
- **Error Responses:**
  - **400 Bad Request:** Short code format is invalid (contains characters outside the Base62 set).
  - **404 Not Found:** Short code does not exist in the database.

---

### 3.5. Get URL Analytics
Retrieves aggregated click analytics (referrers, countries, devices, browsers, and daily trends over the last 7 days) for a given short code. If the link was created by a guest, any user can view the analytics. If the link was created by an authenticated user, only the owner can view the analytics.

- **URL:** `/api/v1/analytics/{short_code}`
- **Method:** `GET`
- **Headers:**
  - `Content-Type: application/json`
  - `Authorization: Bearer <JWT_TOKEN>` *(Optional/Required depending on ownership)*
